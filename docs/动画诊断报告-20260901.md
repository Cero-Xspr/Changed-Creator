## 一、Changed 官方动画时间线（反编译常量，progress ∈ 0..1）

从 `TransfurAnimator` 字节码读出的分段（`Mth.map` + `clamp` 的参数）：

| 区间 | 阶段 | 说明 |
|---|---|---|
| 0.00 – 0.33 | cover | 乳胶覆盖爬满全身（`getCoverProgression` 0→1） |
| 0.20 – 0.35 | preMorph | 人形姿势过渡（下蹲/趴伏，`easeInOutSine`） |
| 0.33 – 0.45 | coverAlpha | 覆盖层淡出（1→0），同时 morph 升起 |
| 0.35 – 0.45 | morph↑ | `getMorphAlpha` 0→1，**0.45 时已是完整兽形** |
| 0.45 – 0.80 | hold | morphAlpha 保持 1 |
| 0.80 – 0.85 | morph↓ | morphAlpha 1→0（morph 几何整体淡出） |
| ≥ 0.85 | 接管 | 捕获态真实模型（普通渲染路径）接管 |

CC 当前的关键常量：`EditedModelLayer.POST_MORPH_START=0.85`、`FADE_START=0.9`、自定义块 spawn 窗口 `0.5..0.833`（`Cube.emit`）、inflate `1.04`。

## 二、视频里实际看到的现象 → 根因映射

### 现象 1：80%–85% 之间"无头身体"／半截模型消失（最严重）
- **根因：交接真空。** 三方时序对不齐：
  - `LivingEntityRendererSkipMixin` 从 `render` HEAD 就 `SKIP_VANILLA=true`（整个渲染期）；
  - Changed 的 morph 几何在 0.80–0.85 期间 alpha 渐没（它本来指望着普通渲染在底下垫着）；
  - `EditedModelLayer` 要等 `progress ≥ 0.85` 才开始画本体（`POST_MORPH_START`）。
  - 三者叠加 → 0.80–0.85 约 0.3 秒里，原版方块被跳过、morph 几何在淡出、layer 还没接手 → 身体缺块。头部最先没是因为头的可视面积全在被跳过的原版方块里。
- **次要嫌疑（需日志验证）**：`EditedModel.Node.dedupeSiblings` 在根层丢弃"名字出现在兄弟子树里"的部件，若编辑器 JSON 里根层 `Head` 与 `Torso` 子树内某个同名部件撞名，layer 绘制会整个丢掉头。建议给 dedup 加一行 debug 日志列出被丢弃的部件名。

### 现象 2：完成瞬间"闪一下"（尺寸+贴图同时跳变）
- inflate 不一致：morph 段自定义块按 `1.04` 画（`Cube.emit` 里 `partialTick<1` 分支），layer 基底 pass 传 `partialTick=1f` 走的是**无 inflate** 分支 → 交接瞬间块整体缩小 4%。
- 贴图体系分裂：morph 段身体走 `isCapturing()` 保护用**原版贴图+原版 UV**（`LivingEntityRendererMixin` 第 2 分支），自定义块用编辑器贴图；0.85 后整体切换为编辑器 UV → 颜色/纹理跳变。

### 现象 3：中段重影／双份轮廓
- morph 段 Changed 画的是 tint 色几何体，CC 同时在同一位置画 1.04 膨胀的贴图块 → 同一部位两层表面叠加，边缘发虚、有重影。这是"平行渲染"架构的固有产物。

### 现象 4：新块出现节奏错乱（"身体先变完，附件才飞过来"）
- Changed 在 0.45 已到 full-beast，而 CC 自定义块 spawn 窗口是 `0.5..0.833` → 身体早就是兽形了，耳朵/尾巴等新块最后 1/3 才陆续飞出来，和原版"块随 morph 一起长出来"的感受相反。
- 且 0.80–0.85 期间 `applyTransitionPose` 用 `morphAlpha`（正在 1→0）把部件 pose **往回插值到人形**，而块还在飞 → 反向甩动 + 穿模。

### 现象 5：解除（反向）时蓝色纹路渗色、果冻化膨胀、头陷入躯干
- 反向播放时 cover/morph 分段倒序，CC 的 0.85 阈值、spawn 窗口、tint 壳全是按正向写的 → 反向时序完全错位。
- "果冻化"一半是 Changed 自身逐顶点 lerp 的观感，另一半是 CC 块 inflate 1.04 + 直线飞行路径穿过身体放大了畸形。
- 蓝色纹路 = 人形皮肤（蓝纹）与编辑器贴图在反向混叠期间的错误采样。

### 现象 6：tint 壳"橙/红色闪现再渐隐"
- `EditedModelLayer` 0.85–0.9 之间用 `entitySolid`（不透明）画 tint 壳，0.9 才切 `entityTranslucent` 开始渐隐 → 有一段实心色块闪现。应全程 translucent。

### 现象 7：光照反转残留
- `Cube.emitBox`（无 `faces` 数组的盒子）不取反法线；`isCustom` 靠 `uvLayout` 存在性判断，旧数据/手写数据不成立 → 部分块仍然背光。

## 三、修复方案

### 方案 A（推荐·战略）：把自定义块注入 Changed 的 morph 几何，删掉平行渲染

核心思路：不再"另画一份"，而是让 Changed 自己的 morph 机制带上我们的块。

- Hook `TransfurAnimator.capture(ModelPart, PoseStack)`（或 `deepCopyPart`），把 `EditedModel` 的自定义 cube 追加进 beast 侧 `EntityGeometry`；humanoid 侧加等数量的占位小立方（藏在对应关节原点），`matchCubeCount` 会自然对齐/拆分。
- 之后 Changed 原生的逐顶点位置/UV/alpha 插值、`MASS_SORT`、`PRIORITIZE_SKELETON` 全部自动生效：
  - 交接真空消失（没有第二套渲染就没有交接）；
  - 重影消失（只有一层几何）；
  - 跳变消失（UV/尺寸全程同一套插值）；
  - 反向动画自动正确（Changed 自己处理倒放）；
  - spawn 节奏自动与 morph 对齐（`lerpCube` 从占位小立方长到目标块，正是用户想要的 animFrom 效果）。
- 可删除：`TransfurAnimatorMixin.changedcreator$renderEditedInMorphLimb`、`EditedModelLayer` 的 0.85 接管+tint 白贴图壳+渐隐、`Cube.emit` 的 spawn 窗口/easeOutCubic/animFrom 手工插值。
- 风险与注意：
  - `TRANSITIONS_CACHE` 按 `ModelPart` 缓存过渡几何 — 编辑器保存后必须清掉对应缓存（否则改动不生效）；
  - `EntityGeometry$Cube/Polygon/Vertex` 是内部类，需按字节码签名构造（先 javap 确认构造器）；
  - 注入的 cube 要带编辑器 UV，否则 morph 中段采样错乱。

### 方案 B（战术·快速止血，可先行合入）

1. `POST_MORPH_START` 0.85 → **0.80**（与 morphAlpha 淡出同步），layer 基底以 `(1-morphAlpha)` ramp 淡入，填掉真空窗口。
2. `SKIP_VANILLA` 门控：动画期间仅 `progress ≥ 0.8` 才跳过原版方块（其余时段让 Changed 的原版渲染正常垫底）。
3. inflate 统一为常量（如 `INFLATE=1.04f`），基底 pass 与 tint 壳、morph 段三处共用 → 消除交接尺寸跳变。
4. spawn 窗口 `0.5..0.833` → **`0.30..0.55`**（贴着 morph 上升沿），确保 0.8 前全部就位。
5. `applyTransitionPose` 在 `morphAlpha` 回落段（progress>0.8）**保持 t=1 不回插值**，避免块反向甩动人形。
6. tint 壳全程 `entityTranslucent`（删掉 `entitySolid` 分支），渐隐起点 0.9 → 0.85。
7. `dedupeSiblings` 增加被丢弃部件的 debug 日志，验证"无头"是否为根部件被 dedup。
8. `emitBox` 法线同样按 editorMade 取反；`isCustom` 判定增加 id 前缀兜底（`uvLayout` 缺失的旧数据）。
9. 反向（解除）动画：若不采用方案 A，至少把上述所有阈值判断改为对称（反向时 0.15–0.2 段是"接管→morph"的交接，同样有真空）。
