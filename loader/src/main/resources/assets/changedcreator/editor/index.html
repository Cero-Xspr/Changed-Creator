胶兽编辑器 Changed Creator

自定义形态

    原版示例

    选择原版示例可参考其属性与模型。

    导入导出

    导出文件可放到游戏内 config/changedcreator/imports/ 由游戏内界面导入热生效。

    没有可用模型：请先在游戏中变身为该形态（进入世界后编辑器可提取真实模型结构），或选择原版示例。
    点轴=步进一格（Alt 反向）；Ctrl/Shift 多选；Ctrl+Z 撤回
    方块编辑

    点预览选中方块。G/R/S 切换拖拽轴。

    移动 间隔
    X Y Z
    旋转 间隔(°)
    RX RY RZ
    SX
    SY
    SZ
    贴图编辑（画笔 / 填充 / 取色）

    贴图编辑：直接在下方画布画，模型上引用该像素的面会同步变色。
    模型编辑：点选方块，中间面板或预览拖拽轴（G 移动 / R 旋转 / S 缩放）；E 进入贴图编辑； 箭头键移动视角，U 还原。Ctrl+Z 撤回模型或贴图。

    基础
    能力 abilities（每行一个）

    可用能力加载中…（填错会导致变形失败，请从列表选）

    属性 properties（JSON）

    可选字段：gills / canClimb / nightVision / reducedFall / glide / doubleJump / extraJumps / quadrupedal / noLegs / disableItems / holdItemsInMouth / cameraZOffset / sound
